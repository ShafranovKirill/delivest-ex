## Границы результата

Настоящие счётчики/кабинеты и production не подключались. Тестовые ответы API не доказывают внешнюю привязку, модерацию фида, индексацию или производственную пропускную способность. Для живой приёмки нужны разрешённый кабинет, счётчик и пилотный филиал. Она проводится по [порядку подключения](implementation.md).

ROAS/CPA доступны только при доверенной настройке связи кампании, достаточном покрытии F04 и полном импорте расходов. Смена текущей связи влияет на классификацию истории ссылки; это показано в админке. Выручка не объявляется причинным приростом. Неизвестная отправка не повторяется автоматически как новая покупка.

Операционные тесты использовали отдельные test/e2e-БД. Существующие пользовательские, demo и production БД не мигрировались. Созданные тестовые БД сохранены для диагностики; одноразовые Docker-контейнеры nginx удалены скриптом.
