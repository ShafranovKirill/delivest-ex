# Подтверждение завершения обмена с роботом

<!-- markdownlint-disable-file -->

Подтвеждает роботу доставщику что загрузка товара завершена.

Вызов этого метода возможен только для точек маршрута
где обязательно подтверждение завершения обмена.

После подтверждения обмена, робот перейдет к следующей точке маршрута.
