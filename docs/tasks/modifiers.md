# Задача: модификаторы

Модификаторов нет: размер пиццы — отдельный товар, добавок нет, в Яндекс Еду уходит `modifierGroups: []`. У всех агрегаторов, CRM и POS они есть, и формат у всех почти одинаковый.

## Решения

| Вопрос | Решение |
|---|---|
| Размер и тесто | Тоже модификаторы: обязательная группа с одним выбором. Отдельных вариантов товара нет |
| Библиотека | Группа создаётся один раз и подключается к многим товарам: «Добавки к пицце» на 20 пицц |
| Цена | У модификатора своя цена, может быть 0 и отрицательной не может. Цена позиции = товар + модификаторы |
| Артикулы | У модификатора артикул на каждую CRM, как у товара (`product_external_ids`) |
| Стоп | Модификатор можно поставить в стоп так же, как товар |

## Модель

| Таблица | Поля |
|---|---|
| `modifier_groups` | название, `min`, `max`, порядок, активность, признак «размер» — для CRM со шкалой размеров (iiko `productSizeId`) |
| `modifiers` | группа, название, цена, `max_quantity` (сколько раз можно добавить), по умолчанию выбран, вес, порядок, активность |
| `product_modifier_groups` | товар, группа, порядок |
| `external_ids` | Общая таблица вместо `product_external_ids`: тип сущности (`product`, `modifier`, `modifier_group`, `category`), id, филиал, провайдер, артикул. Уникально `(тип, филиал, провайдер, артикул)`. У iiko артикулы — UUID, у r_keeper — числа, у Frontpad — цифры: всё строкой |
| `modifier_stops` | как `product_stops` |
| `order_item_modifiers` | позиция заказа, `modifier_id` (может быть пустым), название группы и модификатора, цена, количество — снимок |

Правила группы: `min = 1, max = 1` — обязательный выбор одного («Размер»), `min = 0, max = 3` — до трёх добавок. Модификатор с `max_quantity > 1` — «двойной сыр».

## Корзина и цены

- Позиция корзины — товар + выбранные модификаторы. Одинаковый товар с разными добавками — разные позиции.
- Проверка выбора на сервере: обязательные группы заполнены, лимиты соблюдены, модификаторы активны и не в стопе.
- Акции: процентная скидка на позицию действует на позицию с модификаторами; «товар за N ₽» заменяет цену товара, модификаторы сверху. **Обсудить**, если акции на конкретный размер понадобятся.
- Деньги — в копейках, см. [money.md](money.md).

## Интеграции

| Куда | Как |
|---|---|
| Яндекс Еда, меню | `modifierGroups` и `modifiers` из наших групп, стоп-лист модификаторов |
| Яндекс Еда, заказ | `items[].modifications` → `order_item_modifiers` по id |
| Frontpad | Модификатор — отдельный товар с `product_mod[i]` = индекс родителя |
| iiko | Группа-размер → `productSizeId`, остальные → `modifiers[]` с `productGroupId`, см. [iiko.md](iiko.md) |
| Чек | Модификатор с ценой — отдельной строкой, бесплатный — в название позиции |
| Яндекс Доставка | Название позиции с модификаторами, цена суммой |
| Кухня, печать, курьер | Модификаторы под позицией |

## Экраны

- Админка: библиотека групп, подключение групп к товару, стопы модификаторов, артикулы CRM.
- Клиент: карточка товара с выбором (размер переключателем, добавки списком), цена пересчитывается сразу.
- Кухня и чек кухни: модификаторы под позицией.

## Не входит

- Комбо и наборы. Они есть у iiko (`combos`), r_keeper и Яндекс Еды — модель позиций не должна им мешать: позиция заказа может получить родителя (`parent_id`) без переделки модификаторов.
- Цена добавки, зависящая от размера.
