# Бэклог

Порядок сверху вниз.

## 1. CI на сервере

`mix format --check-formatted` падает: локально Elixir 1.17, в CI 1.19.5-otp-28, новый форматтер требует скобки в `lib/delivest_web/components/staff/app/command_search.ex:35` и `:79`.

- Поставить скобки: `(searchable?(query) and branch) && can?(...)`.
- Закрепить локальную версию под CI (`.tool-versions`: elixir 1.19.5-otp-28, erlang 28.3.1).
- Прогнать тесты, credo и dialyzer — в CI они не запускались с 27.10, после format может вылезти ещё.

## 2. Смена статуса в событиях

Вместо «Order status changed» — «Статус: Принят → Готовится». `from` и `to` уже лежат в metadata события `order.status_changed`, меняется только текст в `log_live/event_text.ex`.

## 3. Строка «Доставка от…»

Только в корзине и в форме оформления заказа. С главной, карты и остальных экранов убрать.

## 4. Настройки в админке

Общий паттерн для настроек филиала, франшизы и вкладки «Доставка»: сначала список разделов карточками, по клику — страница раздела со своим URL. Назад и обновление страницы работают, на раздел можно дать ссылку.

- Вкладка «Доставка» филиала: две карточки — «Зоны доставки» и «Курьеры филиала».
- Настройка источника курьеров переезжает из настроек филиала во вкладку «Доставка».
- Настройки филиала и франшизы разбиваются на разделы так же.

## 5. E2E

Playwright поверх docker compose. Запуск на PR в `main` и раз в сутки.

Сценарии:

- клиент оформляет доставку;
- заказ проходит оператор → кухня → курьер → завершён;
- самовывоз и зал до выдачи, экран выдачи;
- отмена и откат статуса;
- настройки филиала: зоны и курьеры;
- касса: заказ в зале, оплата, чек.

## 6. Хранение событий

Аудит хранится 180 дней (`config :delivest, Delivest.Audit, retention_days: 180`), это и есть полгода — менять нечего. Технические логи — 7 дней, ошибки — 30.
