# Задача: когда заказ можно менять

Сейчас `Orders.Update` и `OrderDraft.fetch_editable` запрещают правку, только если заказ ушёл в CRM. Можно править завершённый и отменённый заказ, заказ у курьера, заказ Яндекс Еды. Откат статуса возможен из `completed` и `cancelled`.

С оплатами и чеками это даёт расхождения: чек пробит на одну сумму, заказ стал другим.

## Решения

| Вопрос | Решение |
|---|---|
| Где правило | Один модуль `Oms.OrderLock`: `check(order, change)` → `:ok` или `{:error, причина}`. Его зовут и формы админки, и `Update`, и API |
| Оплаченный заказ | Правка с доплатой или возвратом, до передачи курьеру. См. [payments.md](payments.md) |
| Откат статуса | Нельзя за точку чека и оплаты без возврата |
| Интеграции | Правка шлёт `order.updated` с тем, что поменялось. CRM, Яндекс Доставка, чеки решают сами, см. [order-events.md](order-events.md) |

## Что можно менять

| Состояние | Состав | Адрес | Время | Способ оплаты | Комментарий |
|---|---|---|---|---|---|
| До `preparing` | да | да | да | да | да |
| Готовится | да, кухня видит изменение | да | да | да | да |
| Готов, ещё не у курьера | да | да | — | да | да |
| У курьера (`delivering`) | нет | нет | — | только наличные ↔ карта | да |
| Завершён, отменён | нет | нет | нет | нет | нет |
| Ушёл в CRM | нет, правка в CRM | нет | нет | нет | да |
| Заказ канала | нет, цены и состав от агрегатора | нет | нет | нет | да |
| Есть оплата | да, с доплатой или возвратом | да | да | нет | да |
| Есть чек прихода | только через возврат и новый чек | да | да | нет | да |

Причина отказа — понятный текст в админке: «Заказ у курьера», «Заказ Яндекс Еды».

## Откат статуса

- Из `completed` — только если нет чека и оплаты, или вместе с возвратом.
- Из `cancelled` — если по заказу не было возврата.
- Если заказ у курьера (`Couriers.handed_over?`), откат как сейчас запрещён.

## Проверить

- Правка заказа канала пересчитывает цены по нашему меню (`Pricing.run`) вместо фиксированных цен канала (`OrderPricing.fixed`).
- Правка заказа без клиента подставляет телефон `+7` (`OrderDraft.with_customer`).
