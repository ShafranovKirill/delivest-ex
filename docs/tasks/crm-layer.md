# Задача: слой CRM под iiko и r_keeper

`Crm.Provider` сейчас описывает Frontpad: заказ создаётся синхронно, после отправки его нельзя ни отменить, ни поправить, статусы — вебхуком по кодам ресторана. iiko и r_keeper устроены иначе. Слой меняется один раз, до первой из них. Frontpad продолжает работать без изменений поведения.

## Что меняется

| | Сейчас | Нужно |
|---|---|---|
| Создание | `deliver_order/2` → `{:ok, external_id}` | Ещё `{:pending, ref}`: iiko команда с `correlationId`, r_keeper `taskGuid`. Состояние `crm.status = confirming`, подтверждение колбэком `confirm_order/2` (вебхук или опрос). Не подтвердилось за N минут — повтор с тем же id |
| Идемпотентность | Нет | Провайдер говорит, можно ли повторять с тем же id (`idempotent?/0`). iiko — да (`order.id`), Frontpad — нет: повтор только после проверки, что заказ не создан |
| Возможности | Нет | `capabilities/0`: `[:cancel, :update_items, :update_comment, :update_address, :update_time, :update_payments]`. Frontpad — `[]`, iiko и r_keeper — почти всё |
| Отмена | Тревога «отмените вручную» | Если есть `:cancel` — `cancel_order/3` с причиной, тревоги нет |
| Правка | Заказ в CRM не редактируется | Что разрешено — по `capabilities`, решает `OrderLock` ([order-changes.md](order-changes.md)). Правка уходит `update_order/3` по событию `order.updated` с изменёнными полями |
| Статусы | Таблица кодов филиала | Провайдер выбирает: `status_map/1` из настроек (Frontpad) или фиксированная в коде (iiko, r_keeper) |
| Откуда статусы | Вебхук | Вебхук, опрос (`Integrations.Poller`, r_keeper) или оба (iiko) |
| Курьер | Не передаём | Если везёт наш курьер — имя и телефон в CRM (r_keeper `pickup.courier`, iiko `update_order_courier`) |
| Справочники | Коды оплат, отметки Frontpad | Общий механизм: провайдер отдаёт справочник (типы оплат, типы заказа, валюты, причины отмены), админка показывает сопоставление «наше значение → значение CRM» |
| Меню | Только сверка артикулов | Импорт меню из CRM, см. [menu-import.md](menu-import.md) |
| Артикулы | Только товары | Товары, модификаторы, группы модификаторов, размеры — общая таблица внешних id, см. [modifiers.md](modifiers.md) |

## Не меняется

- Одна CRM на филиал, embed `orders.crm`.
- `Crm.Registry`, маршруты источников, стоп-лист, сверка меню.
