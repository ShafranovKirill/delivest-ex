# Задача: часовой пояс франшизы и филиала

Сейчас зона одна на всё приложение: `LocalTime.timezone()` берёт `config :delivest, :timezone`, по умолчанию `Europe/Moscow`. На ней стоп «до конца дня», расписание, `cook_by`, аналитика, рабочий день для [номеров заказов](order-numbers.md).

## Решения

| Вопрос | Решение |
|---|---|
| Где задаётся | В настройках франшизы: `Franchise.Settings.timezone`, IANA, по умолчанию `Europe/Moscow` |
| Филиал в другой зоне | Необязательное `branch_info.timezone`. Пусто — зона франшизы |
| Конфиг | `config :delivest, :timezone` убирается |
| Как читать | `LocalTime.timezone(branch)` — зона филиала или франшизы. Без филиала — зона франшизы |

## Что переводится

- Стоп «до конца дня» и снятие в 05:00 — по зоне филиала.
- Расписание и приём заказов — по зоне филиала.
- `cook_by` — `naive_datetime` в зоне по умолчанию. Перевести в `utc_datetime`: в разных зонах наивное время неоднозначно. Показ и ввод — в зоне филиала.
- Яндекс Еда: `Clock.local` и `accept_by` — по зоне филиала.
- Аналитика: день и час по зоне филиала, по сети — по зоне франшизы.
- Номера заказов: рабочий день — по зоне филиала.

## Экраны

- Настройки франшизы: выбор зоны списком городов России (Калининград … Камчатка).
- Настройки филиала: «Часовой пояс как у франшизы» или другой.
