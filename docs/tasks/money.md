# Задача: деньги в копейках

Все суммы сейчас — целые рубли. Кассы, эквайринг и агрегаторы считают в копейках, и мы уже теряем их на входе и на скидках:

| Где | Что |
|---|---|
| `yandex_eda/order_request.ex` | `floor(value)` на всех суммах заказа |
| `yandex_eda/order_pricing.ex` | `base_price: div(total, quantity)` |
| `promo/effects/product_prices.ex`, `cart_discounts.ex` | `div(x * percent, 100)` — процент до рубля |
| `frontpad/api.ex` | `round(price)` |
| `net/product.ex` | `old_price` — строка |

## Решения

| Вопрос | Решение |
|---|---|
| Хранение | Копейки, `integer` (`bigint` в БД). Никаких `float` для денег |
| Валюта | Рубль, отдельного поля нет. Появится — `currency` рядом с суммой |
| API клиента | Копейки целым: `"price": 59000`. Форматирует клиент |
| Админка | Ввод в рублях с копейками: `599,90`, `590`. Показ без `,00` у целых |
| Округление и распределение | Один модуль `Money`: формат, разбор ввода, распределение суммы по долям методом наибольшего остатка. `Promo.Allocation` переезжает туда |
| Проценты | Считать в копейках, округлять до копейки. Округление до рубля — только если так настроено (наценка Яндекс Еды `round_to`) |

## Что переводится

- Каталог: `products.price`, `products.old_price` (строка → `integer`), цены `channel_products`.
- Корзина и заказ: позиции, `subtotal_amount`, `total_amount`, `discount_amount`, `delivery_amount`.
- Акции: фиксированные скидки, лимиты (`cap`), пороги, цены «товар за N ₽», подарки.
- Доставка: цены и пороги зон.
- Курьеры: расчёты (`couriers/settlement.ex`, `cash.ex`).
- Аналитика: суммы, средний чек.
- Интеграции: Frontpad и Яндекс Доставка получают рубли — перевод на выходе; Яндекс Еда — на входе и в меню.

## Перенос

- Миграция `× 100` по всем денежным колонкам одной транзакцией, вместе с JSON (`orders.promotions`, `channel.details`, условия акций).
- Клиент и сервер выкатываются вместе: поле API меняет смысл. Либо версия API, либо одновременный релиз — решаем при выкатке.
- Тест-страховка: свойство «сумма позиций = итог заказа» на случайных корзинах с акциями.

## Не входит

- Мультивалютность.
- Хранение НДС в позиции — в [фискализации](fiscal-receipts.md).
