# Задача: импорт меню из CRM

Рестораны на iiko и r_keeper ведут меню в своей системе. Вести его второй раз у нас они не будут. Поэтому у филиала есть источник меню: наше или из CRM.

## Решения

| Вопрос | Решение |
|---|---|
| Источник меню | Настройка филиала: `own` (ведём у нас, CRM только сверка — Frontpad) или `crm` (меню приходит из CRM — iiko, r_keeper) |
| Что приходит из CRM | Товары, категории, цены, группы модификаторов и модификаторы, размеры, вес, КБЖУ если есть, активность |
| Что остаётся нашим | Фото, описание для витрины, порядок и группировка на витрине, теги, видимость в приложении, цены каналов (`channel_products`) |
| Связь | Через общую таблицу внешних id ([modifiers.md](modifiers.md)): товар CRM ↔ наш товар. Импорт находит наш товар по артикулу и обновляет, новый — создаёт |
| Удалено в CRM | Наш товар скрывается, не удаляется: на него ссылаются заказы, фото и акции |
| Когда | Кнопка «Обновить меню» и по расписанию. iiko — ещё по вебхуку о смене меню, если появится |
| Конфликт | Поля из CRM в форме товара только для чтения с пометкой «из iiko». Наши поля редактируются как обычно |
| Каталог сети | Товары общие для сети. Импорт идёт из одного филиала-эталона, остальные филиалы сверяются с ним по артикулам. Разные меню у филиалов одной CRM — **обсудить** при первом таком клиенте |

## Провайдер

Необязательные колбэки `Crm.Provider`:

- `menu_source?/1` — умеет ли CRM отдавать меню целиком;
- `fetch_menu/1` → нейтральная структура: категории, товары, размеры, группы модификаторов, модификаторы, у каждого внешний id и цена в копейках.

| CRM | Откуда |
|---|---|
| iiko | `POST /api/menu/v3/by_id` (внешнее меню), размеры — `sizePrices`, группы модификаторов с `min`/`max` |
| r_keeper | `GetMenu`, `GetMenuByParams` |
| Frontpad | Нет — только `get_products` для сверки, меню наше |

Импорт — один модуль `Net.MenuImport`: дифф «что добавится, изменится, скроется», показ диффа в админке, применение одной транзакцией с событием `menu.imported`. Каналы (Яндекс Еда) узнают через `Channels.menu_changed/1`.
