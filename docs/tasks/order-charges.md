# Задача: сборы и надбавки заказа

Сейчас из сборов есть только `delivery_amount`. Агрегаторы и POS передают сервисный сбор, упаковку, чаевые, комиссию. В чеке каждая — своя строка со своим признаком.

Делать после [оплат](payments.md) и [копеек](money.md), когда понадобится первый сбор кроме доставки.

## Модель

`order_charges`: заказ, вид (`delivery`, `service`, `packaging`, `tip`), название, сумма, ставка НДС, источник (наш расчёт, канал, CRM).

- Доставка переезжает сюда, `delivery_amount` остаётся вычисляемым для совместимости.
- Итог заказа = позиции − скидки + сборы.
- Чаевые не входят в выручку и в чек — отдельно, как оплата сверх итога.
- Комиссия агрегатора — не сбор с клиента, а данные для отчёта: в `channel.details`.
